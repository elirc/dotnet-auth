# Risk Register

| Risk | Evidence | Impact | Likelihood | Suggested Test | Suggested Fix | Confidence |
| --- | --- | --- | --- | --- | --- | --- |
| No real pinned commit | `git rev-parse HEAD` failed; see [`verification-log`](verification-log.md). | Line anchors can drift until first commit. | High | Commit scaffold before extending docs. | Make an initial commit, rerun anchor audit. | Confirmed |
| Backend not locally verified | `dotnet --version` failed; see [`verification-log`](verification-log.md). | C# compile/runtime errors may remain. | Medium | Install .NET 8 and run CI commands from [`ci.yml`](../../../.github/workflows/ci.yml#L16-L18). | Fix compile errors, generate migrations. | Confirmed |
| Tenant isolation may rely on request tenant ID | Admin endpoints accept `tenantId` from query/body in [`AdminController`](../../../src/NetAuth0.Api/Controllers/AdminController.cs#L15-L38); token has tenant claim in [`JwtTokenIssuer`](../../../src/NetAuth0.Infrastructure/Security/JwtTokenIssuer.cs#L26-L34). | Cross-tenant data exposure or mutation. | High in multi-tenant use | Two-tenant integration test where token tenant differs from requested tenant. | Derive tenant from claims or add tenant membership/resource authorization handler. | High |
| Formal hosted authorize endpoint accepts `user_id` | [`OAuthController.Authorize`](../../../src/NetAuth0.Api/Controllers/OAuthController.cs#L13-L31) binds `user_id` from query. | Any caller may mint code for a user ID if other checks pass. | High if exposed beyond learning use | Authorization request without authenticated browser session should fail. | Bind authorize to authenticated hosted-login session and consent state. | Confirmed |
| Refresh rotation lacks explicit transaction | [`ExchangeRefreshTokenAsync`](../../../src/NetAuth0.Application/OAuth/OAuthService.cs#L209-L228) inserts replacement, saves, then marks original replaced and saves again. | Partial token-family state after failure. | Medium | Fault-injection test between saves. | Wrap rotation in transaction or redesign as single unit of work. | High |
| No compiled EF migrations | Startup falls back to `EnsureCreatedAsync` when no migrations exist in [`Program`](../../../src/NetAuth0.Api/Program.cs#L138-L150). | Production schema drift and migration rollback impossible. | High | Generate migration and run database update in CI. | Add migrations and remove production `EnsureCreated` fallback. | Confirmed |
| Private signing keys stored as DB PEM | [`SigningKey`](../../../src/NetAuth0.Domain/Identity/IdentityEntities.cs#L280-L297) stores `PrivateKeyPem`; mapping stores text in [`AppDbContext`](../../../src/NetAuth0.Infrastructure/Persistence/AppDbContext.cs#L108-L112). | DB compromise exposes signing keys. | Medium | Security review and secret-storage test. | Encrypt at rest with Data Protection/KMS or use external key service. | High |
| Admin dashboard stores access token in localStorage | [`LoginPage`](../../../frontend/src/pages/LoginPage.tsx#L33-L37) writes token to localStorage. | XSS can steal bearer token. | Medium | Threat model and XSS regression checks. | Consider secure cookie session for first-party admin or strong CSP/short token lifetimes. | High |
| Missing request validation layer | Controllers accept request DTOs directly in [`AuthController`](../../../src/NetAuth0.Api/Controllers/AuthController.cs#L14-L27) and [`AdminController`](../../../src/NetAuth0.Api/Controllers/AdminController.cs#L20-L31). | Invalid inputs reach business services; inconsistent errors. | High | Validation failure tests. | Add FluentValidation validators and map errors consistently. | High |
| Sparse tests | Only PKCE helper test found in [`SecurityTests`](../../../tests/NetAuth0.UnitTests/SecurityTests.cs#L6-L19). | Core auth regressions can ship. | High | Add unit/integration coverage for listed flows. | Prioritize token, tenant, MFA, and admin tests. | Confirmed |
| Key rotation lacks audit event | Rotation endpoint returns key ID in [`AdminController`](../../../src/NetAuth0.Api/Controllers/AdminController.cs#L72-L77), but no audit write is visible there. | Security-sensitive action has weak traceability. | Medium | Rotate key and search audit log. | Inject audit writer into rotation service or endpoint. | High |
